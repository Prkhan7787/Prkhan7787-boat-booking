# Boat Booking System

เว็บจองเรือจากโปรเจกต์เดิม ใช้ HTML, CSS และ JavaScript ที่ทำงานในเบราว์เซอร์ ข้อมูลเรือและการจองเก็บไว้ใน `localStorage` ของอุปกรณ์นั้น ไม่มีฐานข้อมูล ไม่มีระบบสมาชิก และไม่ต้องเข้าสู่ระบบ

## เริ่มใช้งาน

ต้องมี Node.js 18 ขึ้นไป

```sh
cd backend
npm install
npm start
```

เปิด http://localhost:5000 เพื่อใช้งานเว็บไซต์ `npm install` ไม่ต้องดาวน์โหลด dependency เพิ่มเติม

## การใช้งาน

- ค้นหาและดูรายละเอียดเรือจากรายการตัวอย่างหรือรายการที่เพิ่มไว้
- กด **เพิ่มเรือ** แล้วกรอกชื่อ รูปภาพ ประเภท จำนวนที่นั่ง ราคา รายละเอียด สถานที่ให้บริการ และเบอร์ติดต่อ
- ข้อมูลเรือที่เพิ่มและรายการจองจะถูกเก็บใน `localStorage` และแสดงบนเบราว์เซอร์เดิมทันที
- เลือกเรือ ระบุชื่อและเบอร์โทรผู้จอง วัน เวลา จำนวนผู้โดยสาร และหมายเหตุ แล้วกดยืนยัน
- หน้ายืนยันแสดงรหัสจองและดาวน์โหลดรายละเอียดเป็นไฟล์ข้อความได้

ข้อมูลใน `localStorage` เป็นข้อมูลเฉพาะเบราว์เซอร์และอุปกรณ์ปัจจุบัน การล้างข้อมูลเว็บไซต์หรือใช้อุปกรณ์อื่นจะไม่เห็นข้อมูลเหล่านี้ และเว็บไซต์แบบนี้ไม่มีการซิงก์ข้อมูลระหว่างผู้ใช้

## ตรวจสอบ

```sh
cd backend
npm run check
```
